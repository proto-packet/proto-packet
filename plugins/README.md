# Plugins

This folder holds the ProtoPacket editor plugins.

- `textmate/`: the TextMate bundle with the syntax of schema files, for highlighting.
- `jetbrains/`: the plugin for the JetBrains IDEs, which bundles the syntax & shows the errors.

The plugins aren't built by the root `build.sh`. Run `jetbrains/build.sh` to build & verify the
JetBrains plugin.
